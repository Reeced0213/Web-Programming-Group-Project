# Web-Programming-Group-Project
Group web development project using HTML, CSS, and JavaScript.

This project is a collaborative web development project created by a
5-person team for a Web Programming course.

The webpage is being developed using:
- HTML
- CSS
- JavaScript
- Notepad++

The goal of this project is to create a functional and interactive
webpage while applying concepts learned throughout the course.
